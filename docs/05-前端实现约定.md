# 05 · 前端实现约定（车内交互终端）

> 这份文档是前端代码的**唯一契约**。所有页面都必须只用这里列出的 store / 组件 / 令牌，
> 不新增全局依赖，不引入 UI 框架的默认观感。

---

## 1. 技术边界

| 项 | 约定 |
| --- | --- |
| 框架 | Vue 3 `<script setup lang="ts">`，**组合式 API**，禁止 Options API |
| 状态 | Pinia（`@/stores/*`），禁止在页面之间直接互相 import |
| 样式 | 纯 CSS + `scoped`，**只用设计令牌**（`var(--c-*)` / `var(--fs-*)` / `var(--sp-*)`） |
| 禁止 | Tailwind / UnoCSS / 任何新依赖；禁止内联写死颜色值（十六进制、rgb） |
| 图标 | `IconBase`（`@/components/IconBase.vue`），名称取自 `@/components/icons.ts` |
| 图表 | `@/charts/*`（ECharts 按需引入），禁止在页面里直接 `import * as echarts` |
| 类型 | 从 `@/api/types` 引入，不要在页面里重复定义接口形状 |
| 单位 | 后端金额一律是**分**，展示时用 `formatMoney()` |

**文案红线**：所有用户可见文案里**禁止出现破折号**（`—`、`–`、`——`）。要停顿就用逗号或句号。

**触控红线**：任何可点区域 ≥ **56×56px**；主操作按钮 ≥ 64px 高。禁用 hover-only 交互。

## 3. Store 契约

### 3.1 `useSessionStore()` — `@/stores/session`

```ts
state: ScreenState            // 'IDLE'|'WAITING'|'WELCOME'|'READY'|'TRIP'|'ARRIVING'|'ARRIVED'|'SUMMARY'
vehicle: { id, plateNo, cabinNo, modelCode, battery, cameraOn, micOn } | null
ride: RideView | null         // 后端给的行程快照
needVerify: boolean
verified: boolean             // 是否已通过上车校验（已拿到会话 token）
phases: string[]              // ['前往上车点','准备出发','行程中','即将到达','到达','结束']
message: string
ready: boolean                // bootstrap 是否已完成
bootstrap(): Promise<BootstrapView | null>
verify(code: string): Promise<RideView>     // 失败会抛 ApiError
endSession(): Promise<void>
handleAuthError(e): boolean   // 若为 40100 会清掉 token 并返回 true
```

### 3.2 `useRideStore()` — `@/stores/ride`

```ts
view: RideView | null         // 当前行程
vehicle: VehicleView | null
behavior: { type, short, title, detail, icon, slowsDown, at? } | null   // 当前车辆行为
events: RideEventView[]
stops: StopRequestView[]
status: RideStatusValue
isOngoing: boolean            // ONGOING | ARRIVING
remainTimeS: number           // 已做本地每秒回退，可直接展示
traveledM: number             // 已行驶米数
remainDistanceM: number
progress: number              // 0~1
refresh(): Promise<void>
fetchEvents(limit?): Promise<void>
start(): Promise<void>                      // 乘客确认「开始行程」
changeDestination({ poiId? | name/lng/lat, category? }): Promise<void>
requestStop({ kind:'NORMAL'|'EMERGENCY', poiId?, name?, lng?, lat?, note? })
cancelStop(id): Promise<void>
openDoor(): Promise<{ ok: boolean }>        // 车未停稳会抛 ApiError(42005)
complete(): Promise<void>
rate(score, tags[]): Promise<void>
summary(): Promise<SummaryView>
explain(): Promise<ExplainView>
```

`RideView` 字段：`id, rideNo, status, statusLabel, phase, origin{name,lng,lat}, dest{name,lng,lat,category}, planDistanceM, planDurationS, traveledM, remainDistanceM, remainTimeS, progress, fare{base,distance,time,discount,total}, co2SavedG, ratingScore, verifyHint`

### 3.3 `useCabinStore()` — `@/stores/cabin`

```ts
setting: CabinSetting | null   // tempLeft,tempRight,fanLevel,seatHeat,seatVent,ambientLight,brightness,volume,curtain,scene
scenes: { key, name, desc, icon }[]        // standard | sleep | work | relax | motion
ambientOptions: { key, name, color }[]     // off | warm | neutral | cool
ranges: { temp{min,max,step}, fan, seat, brightness, volume }
sceneName: string
load(); update(patch); applyScene(key)     // update 是乐观更新，失败自动回滚并 throw
```

### 3.4 `useRealtimeStore()` — `@/stores/realtime`

```ts
connected: boolean
notices: { id, kind:'info'|'warn'|'success', title, detail?, at }[]
progress: RideProgressPayload | null
behavior: BehaviorView | null
statusChange: { to, message, at } | null
trackOf(id) / sample(id) / sampleAll()     // 地图用，页面一般不需要
dismissNotice(id)
```

### 3.5 `useUiStore()` — `@/stores/ui`

```ts
theme: 'dark'|'light'|'auto' ; resolvedTheme: 'dark'|'light'
fontScale: 'standard'|'large' ; contrast: 'normal'|'high' ; motion: 'full'|'calm'
voiceEnabled: boolean
cycleTheme() / toggleFont() / toggleContrast() / toggleMotion()
```

### 3.6 直接用 API 的场景

页面需要不在 store 里的数据时，从 `@/api` 引入：

```ts
import { helpApi, vehicleApi, opsApi, cabinApi, rideApi, sessionApi } from '@/api';
```

## 4. 组件契约

### `IconBase`
```html
<IconBase name="car" :size="20" />
```
可用名称见 `@/components/icons.ts`（car, seatbelt, door, sos, alert, info, check, close,
question, fan, thermometer, bulb, volume, volumeOff, curtain, seat, route, pin, clock,
battery, camera, mic, user, star, shield, share, sync, settings, moon, briefcase, sparkle,
motion, wheelchair, textSize, contrast, chevronRight, chevronLeft, chevronDown, plus, minus,
power, wifi, wifiOff, bag, leaf, map, list）

### `AppButton`
```html
<AppButton variant="primary|soft|ghost|danger|quiet" size="md|lg|xl"
           icon="check" icon-right="chevronRight" block :disabled :loading hint="按下去会发生什么">
  按钮文字
</AppButton>
```

### `HoldButton`（破坏性动作专用：长按 1.2 秒）
```html
<HoldButton label="紧急停车" hint="按住 1.2 秒" icon="sos" variant="danger"
            :disabled="!canUse" disabled-reason="行驶中不可用" @confirm="onConfirm" />
```

### 其他
- `<SkeletonBlock :rows="3" :height="16" />` 加载占位
- `<EmptyState icon="info" title="…" detail="…">` + `#action` 插槽
- `<ToastStack />` 已挂在 CabinLayout 上，**页面不要重复挂**
- `<DecisionBubble />` 只在 TripPage 里挂一次

### 地图
```html
<MapCanvas :follow="true" :scale="0.62" :interactive="true" />
```
它自己会从 store 取行程/车辆/轨迹并逐帧渲染，页面**不需要传数据**，只需要给它一个填满父容器的高宽。

## 5. 设计规范摘要（详见 docs/02 §11）

- **深色优先**，层级靠 1px 描边 + 亮度差，几乎不用阴影（`--sh-2` 只在浮层用）
- **唯一强调色** `--c-accent`（柔蓝）。成功/警告/危险只用于**语义**，小面积
- 圆角只用 4 档令牌：`--r-btn`(胶囊) / `--r-card`(24) / `--r-panel`(28) / `--r-input`(14)
- 字号用 `--fs-*`；关键数字加 `class="num"`（等宽，防跳动）
- 动效用 `--d-*` + `--ease-out`；**不要弹跳**（`--ease-spring` 也要收敛）
- **反后台化红线**：不出现左侧导航、面包屑、三栏后台壳、数据表格、筛选行+汇总+表格、
  KPI 卡片墙、饱和色状态标签。车内只有一个"用户视角"，没有"管理视角"
- 空状态必须解释"为什么空 + 接下来能做什么"；加载必须给骨架屏
- 每屏最多 2 个图表

### 常用工具函数（`@/map/geo`）
`formatDistance(m)` → "1.2 公里" / "480 米"
`formatDuration(s)` → "12 分钟" / "1 小时 5 分"
`formatClock(s)` → "07:30"
`formatMoney(cents)` → "24.16"
`formatTime(ts)` → "14:05"

## 8. 错误处理约定

所有写操作都要处理失败：

```ts
try {
  await ride.start();
  router.push('/trip');
} catch (e) {
  if (session.handleAuthError(e)) return router.replace('/verify');
  error.value = e instanceof Error ? e.message : '操作失败，请重试';
}
```

失败提示就地在页面内展示（`role="alert"` 的一行文字），**不要弹窗**。
